隱私權政策｜Privacy Policy

生效日期 Effective date: 2026-09-26

本隱私權政策說明 strait-views-upload（以下稱「本應用程式」）如何收集、使用、儲存及保護您的資訊。本應用程式由 YouTube 頻道「台海局勢，外面怎麼說？」（@TaiwanStraitViews）的頻道主營運，僅供頻道主本人管理自己的頻道使用。
This Privacy Policy explains how strait-views-upload (the "App") collects, uses, stores and protects information. The App is operated by the owner of the YouTube channel @TaiwanStraitViews and is used solely by the owner to manage their own channel.

1. YouTube API 服務 YouTube API Services

本應用程式使用 YouTube API 服務。使用本應用程式即表示您同意受 YouTube 服務條款 約束，並適用 Google 隱私權政策。
The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

2. 我們存取的資訊 Information we access

經您透過 Google OAuth 明確授權後，本應用程式透過 YouTube Data API 存取以下範圍：
・youtube.upload：上傳影片至您的頻道。
・youtube：設定影片標題、說明、標籤、縮圖與排程公開時間，並讀取您自己影片的上傳與隱私狀態。
本應用程式不存取您的聯絡人、電子郵件內容、觀看紀錄、訂閱者個人資料或任何其他 Google 服務的資料。
With your explicit authorization via Google OAuth, the App accesses the YouTube Data API scopes youtube.upload (to upload videos to your channel) and youtube (to set titles, descriptions, tags, thumbnails and scheduled publish times, and to read the upload and privacy status of your own videos). The App does not access contacts, email, watch history, subscriber personal data, or data from any other Google service.

3. 資訊的使用方式 How we use information

上述資訊僅用於執行您發出的上傳與排程指令。我們不將資料用於廣告、分析、剖析或訓練任何模型。
Information is used only to carry out the upload and scheduling actions you request. It is not used for advertising, analytics, profiling, or training any model.

4. Google 使用者資料的限制使用 Limited Use disclosure

本應用程式對於從 Google API 取得之資訊的使用及傳輸，將遵守 Google API 服務使用者資料政策，包括「限制使用」要求。
The App's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 資料分享 Sharing

我們不會出售、出租、分享或轉移任何 Google 使用者資料給第三方。
We do not sell, rent, share or transfer any Google user data to third parties.

6. 資料儲存與保存期限 Storage and retention

OAuth 存取權杖與更新權杖僅儲存在頻道主自己的電腦上，不傳送至任何伺服器，也不存入任何資料庫。本應用程式不保存 YouTube API 回傳的資料；權杖保存至您撤銷授權或刪除為止。
OAuth access and refresh tokens are stored only on the owner's own computer; they are never sent to any server or stored in any database. The App does not retain data returned by the YouTube API. Tokens are kept until you revoke access or delete them.

7. 資料安全 Security

所有與 Google 的連線皆經 HTTPS 加密；權杖檔案存放於本機受保護的資料夾，不納入任何版本控制或公開儲存空間。
All communication with Google uses HTTPS. Token files are kept in a protected local folder and are never committed to version control or public storage.

8. 撤銷授權與刪除資料 Revoking access and deleting data

您可隨時透過 Google 安全性設定頁面 撤銷本應用程式的存取權。撤銷後，本機儲存的權杖即失效；如需刪除，請來信，我們會在 7 天內刪除所有本機權杖。
You can revoke the App's access at any time via the Google security settings page. After revocation the locally stored tokens become invalid; on request we will delete all local tokens within 7 days.

9. 兒童隱私 Children's privacy

本應用程式不以未滿 13 歲之兒童為對象，也不會蓄意收集兒童資訊。
The App is not directed to children under 13 and does not knowingly collect information from children.

10. 政策變更 Changes to this policy

本政策如有修改，將更新本頁並修改上方生效日期。
If this policy changes, we will update this page and the effective date above.
