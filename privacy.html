1. 使用者範圍 Who uses this app

strait-views-upload 僅供「台海局勢，外面怎麼說？」頻道主本人使用，用來管理自己的 YouTube 頻道。
The app is used solely by the owner of the YouTube channel @TaiwanStraitViews to manage that channel.

2. 存取的資料 Data accessed

透過 Google OAuth，本工具取得 YouTube Data API 權限（youtube.upload、youtube），只用於：上傳影片、設定標題／說明／縮圖、設定排程公開時間、讀取自己影片的狀態。
Via Google OAuth the app uses the YouTube Data API scopes youtube.upload and youtube only to upload videos, set titles/descriptions/thumbnails, schedule publication, and read the status of the owner's own videos.

3. 資料儲存 Storage

OAuth 授權憑證只存放在頻道主自己的電腦上，不上傳到任何伺服器。本工具沒有資料庫，不保存、不分析任何 Google 使用者資料。
OAuth tokens are stored only on the owner's own computer and are never sent to any server. The app has no database and does not store or analyze Google user data.

4. 分享 Sharing

不與任何第三方分享、出售或轉移 Google 使用者資料。本工具對 Google API 取得之資料的使用，遵守 Google API Services User Data Policy，包括「限制使用」要求。
No Google user data is shared, sold or transferred to any third party. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 撤銷授權 Revoking access

可隨時到 Google 帳戶的第三方存取權 撤銷本工具的授權。
Access can be revoked at any time at myaccount.google.com/permissions.
